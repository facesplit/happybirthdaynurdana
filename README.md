# Наш год под деревом 🌳

Одностраничный сайт-поздравление с днём рождения в стиле cozy pixel (Stardew-like).
По мере скролла вокруг дерева сменяются сезоны: Рассвет → Весна → Лето → Осень → Зима →
снова Весна (день рождения). Каждый сезон — глава нашего года.

Стек: **Vite** + **Lenis** (плавный скролл) + **GSAP/ScrollTrigger** (привязка к скроллу) +
**Canvas 2D** (частицы). Без бэкенда, собирается в статику.

---

## Быстрый старт

```bash
npm install          # зависимости
npm run photos       # обработать фото из assets/ -> public/photos/*.webp (+ портрет, её фото)
npm run sprites      # (опц., локально) догрузить спрайты Stardew -> public/sprites
npm run couples      # сезонные пары под деревом + лицо рассказчика (Асылхан) из assets/.../
npm run dev          # дев-сервер http://localhost:5173
```

### 🔊 Музыка и звук
- Внизу справа — **плеер**: ⏮ / ⏯ / ⏭ переключают треки, показывается название.
  Запускается при первом действии (клик/скролл). Текст печатается с «блипом», как в Stardew.
- Трек «Ламповая мелодия» — **генеративный** (WebAudio), работает без файлов.
- Свои песни: положи mp3 в `public/audio/` с именами (плеер подхватит их):
  - `porvav-povodok.mp3` — «Порвав поводок»
  - `moldanazar-ozin-gana.mp3` — «Moldanazar — Özıñ Ğana»
  - `pretty-little-baby.mp3` — «Connie Francis — Pretty Little Baby»
  Эти треки защищены авторским правом → в `.gitignore`, не публикуются (только локально).
  Подробности — в `public/audio/README.txt`.

### ✨ Интерактив и пасхалки
- **Клик по фото** — открыть целиком; ещё клик по фото — переключить ориг ⟷ аниме.
- **Клик по дереву** — всплеск сезонных частиц; **по паре** — сердечки;
  **по дому** — вкл/выкл свет в окне; **по торту** (в финале) — загадать желание.
- Иногда по небу летит **падающая звезда** — кликни, чтобы загадать желание ⭐.
- Диалог рассказчика (Асылхан) — многострочный: клик по окну продолжает рассказ.
- Сезонные пиксельные частицы: весна — розовая сакура, лето — зелёные листья,
  осень — оранжевые, зима — белый снег.

Земля и трава генерируются **процедурно** (пиксель-арт в `src/ground.js`) и меняются
по сезонам — отдельные спрайты травы не нужны. Пара под деревом, дом, сундук и дерево —
настоящие спрайты Stardew (локально), с откатом на оригинальный арт без них.

Сборка и предпросмотр статики:

```bash
npm run build        # -> /dist
npm run preview      # локальный сервер для /dist
```

Тесты (Playwright, скриншоты сезонов в `tests/screenshots/`):

```bash
npx playwright install chromium   # один раз
npm test
```

## 🖼 Как заменить/добавить фото

1. Положи исходники в `assets/Наши фотки Оригинал фотки` (и аниме — в `… Аниме версия`).
2. Поправь маппинг имён в `scripts/process-photos.js` (массив `MAP`: slug → базовое имя файла).
3. `npm run photos` — пересоберёт `public/photos/*.webp` + `manifest.json` (с blur-плейсхолдерами).

Распределение по главам: `spring-1..4`, `autumn-1..3`, `winter-1`. У осенних есть
аниме-версия (`*-anime.webp`) — она проявляется по скроллу («вот как я тебя вижу»).

## 🌳 Про спрайты Stardew (важно)

Центральное дерево, домик, сундук и цветы могут рисоваться **настоящими спрайтами
Stardew Valley** (© ConcernedApe) — они догружаются `npm run sprites` в `public/sprites/`
и используются **только локально** (для личного показа). Эти файлы в `.gitignore`
и **не публикуются**.

Если спрайтов нет (чистый клон, публичный деплой) — сайт сам откатывается на
**оригинальный векторный арт** (SVG-дерево, CSS-домик и сундук). Так публичная версия
остаётся чистой по авторским правам. Подробности и лицензии — в [`ASSETS.md`](./ASSETS.md).

## 🚀 Публикация на GitHub Pages

В репозитории есть workflow `.github/workflows/deploy.yml`: на `push` в `main` он собирает
проект и публикует `/dist` на GitHub Pages (`actions/deploy-pages`).

Включить: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

`vite.config.js` использует `base: './'` (относительные пути) — работает и на user-, и на
project-pages. Спрайты Stardew на публичную версию не попадают (см. выше) — будет арт-фолбэк.

## Доступность / производительность

- Учитывается `prefers-reduced-motion`: при включённом — отключаются частицы, плавный
  скролл и автоплей, остаются простые fade.
- На мобилке уменьшено число частиц; дерево/мир — фиксированный слой (без хрупкого пиннинга).
- Фото — WebP ≤1200px + крошечный blur-LQIP для плавной загрузки; видео — `preload="none"`,
  ленивая загрузка при подходе секции.
