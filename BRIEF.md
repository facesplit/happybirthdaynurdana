# BRIEF — Birthday Scrollytelling Site ("Наш год под деревом")

> Вставь этот файл в новый репозиторий и скорми Claude Code как главное ТЗ.
> Стиль: Stardew Valley (cozy pixel-art), нежный/романтичный. Одностраничный скролл-сайт.

---

## 0. Что мы делаем

Одностраничный сайт-поздравление с днём рождения. Главная метафора — большое дерево,
под которым сидит пиксельная пара. По мере скролла вокруг дерева сменяются сезоны
(Весна → Лето → Осень → Зима → снова Весна = день рождения). Дерево запинено в центре,
мир вокруг меняется: цвет неба, листва, частицы, свет. Каждый сезон — глава нашего года.

Сайт должен:
- плавно листаться (инерционный скролл),
- менять сезоны привязанно к прогрессу скролла (scrub),
- показывать фото-воспоминания, видео и финальный «сундук» со ссылками,
- быть лёгким, адаптивным, работать на телефоне,
- собираться без бэкенда и публиковаться на GitHub Pages.

## 1. Технический стек (всё бесплатное, через CDN)

- **Vite** (vanilla, без фреймворка) — дев-сервер и сборка в статику. Можно и чистый HTML,
  но Vite удобнее для дев-режима и сборки под Pages.
- **Lenis** — плавный инерционный скролл (`@studio-freight/lenis` или `lenis`).
- **GSAP + ScrollTrigger** — привязка смены сезонов к скроллу, пиннинг, появление элементов.
  С 2026 все плагины GSAP бесплатны (включая SplitText для текста по словам).
- **Canvas 2D** (нативно) — система частиц (лепестки / светлячки / листья / снег).
  Без тяжёлых библиотек. Опционально Anime.js v4 для мелких декоративных эффектов.
- **Howler.js** (опционально) — фоновая музыка с кнопкой mute (тихая cozy-мелодия).

НЕ используем: тяжёлый Three.js (для 2.5D-параллакса избыточен), localStorage,
никаких платных сервисов и API-ключей.

## 3. Подготовка ассетов

### 3.1 Фото (у пользователя 7 шт.)
Распределение по главам (НЕ по реальной погоде — мы в здании, это неважно, привязка смысловая):
- **Весна** — 3 фото
- **Лето** — фото нет, тут видео (прошлогоднее поздравление)
- **Осень** — 3 фото
- **Зима** — 1 фото
- **День рождения / снова Весна** — новое видео + одно общее фото (если будет)

Обработка фото (сделать скриптом, напр. через `sharp` в Node или ImageMagick):
- конверт в **WebP**, максимальная сторона ~1200px, качество ~80;
- сгенерировать lqip-заглушку (крошечный blur-плейсхолдер) для плавной загрузки;
- именовать осмысленно: `spring-1.webp`, `autumn-2.webp`, `winter-1.webp` и т.д.
- оформлять в UI как пиксельный полароид на верёвочке, который покачивается.

### 3.2 Видео
- прошлогоднее поздравление → `/public/video/last-year.mp4` + `last-year-poster.webp`;
- новое (если запишет) → `/public/video/birthday.mp4` + постер;
- `<video>` с `preload="none"`, `playsinline`, ленивая загрузка (грузить при подходе секции),
  кастомная пиксельная кнопка play.

### 3.3 Пиксель-арт фон и спрайты (Stardew-like)
Гибридный подход:

**Генерируем кодом (надёжно, легко):**
- небо — CSS/SVG градиент, цвет интерполируется по прогрессу скролла;
- дерево — SVG (ствол + крона), листва меняет цвет/форму по сезону;
- частицы — canvas;
- холмы/облака дальнего плана — простые SVG-силуэты для параллакса.

**Скачиваем готовое (для деталей: пара под деревом, домик, сундук, трава, цветы):**
Источники с CC0 / free лицензией — скачать через curl/wget, ОБЯЗАТЕЛЬНО записать
источник и лицензию в `ASSETS.md`:
- **Kenney.nl** — паки `kenney.nl/assets` (CC0, можно качать напрямую). Искать:
  "Pixel Platformer", "Background Elements", "Nature pack".
- **OpenGameArt.org** — фильтр по лицензии CC0/CC-BY. Искать: "seasons tileset",
  "pixel tree parallax", "cozy farm".
- **itch.io** — раздел free game assets. Искать: "free pixel art parallax background",
  "Stardew style tileset", "pixel characters couple". Внимательно к лицензии каждого
  пака (некоторые free, но без редистрибуции — тогда не коммитить, только использовать локально,
  либо взять CC0-аналог).

ВАЖНО про авторские права: не использовать сами ассеты Stardew Valley или другой
коммерческой игры — только оригинальные CC0/свободные ассеты «в духе» стиля.
Стиль (пиксель-арт, cozy-палитра) не охраняется — конкретные спрайты охраняются.

Если подходящий спрайт не найден — нарисовать примитивный SVG-аналог (домик, сундук,
фигурки пары — это простые формы) прямо в коде.

## 4. Сценарий по секциям (контент + поведение)

Палитра — тёплая Stardew: кремовый, мягкий розовый, персик, золото, приглушённая зелень.
Пиксельный шрифт для заголовков (напр. свободный "Press Start 2P" или "VT323" с Google Fonts —
проверить лицензию, они свободные), читаемый шрифт для текста.

**S1 — Рассвет / Интро.**
Пиксельный холм, большое дерево, под ним силуэт двух фигурок. Небо светлеет от
тёмно-синего к рассветно-розовому. Появляется ИМЯ мягким пиксельным шрифтом + подсказка «↓».
Параллакс: облака плывут, трава покачивается. На первом скролле имя уходит вверх с лёгким blur.

**S2 — Весна «Как всё началось».**
Дерево покрывается розовыми цветами, летят лепестки (частицы pink). На ветках появляются
3 весенних фото-полароида на верёвочках, покачиваются, у каждого подпись-воспоминание
(текст пользователь впишет позже — оставить плейсхолдеры `[подпись 1]`).

**S3 — Лето «Наши приключения».**
Дерево густо-зелёное, тёплый свет, летают светлячки (частицы glow). По центру — сцена костра
или «телевизор-воспоминание»: прошлогоднее видео-поздравление, играет по клику. Ламповая сцена.

**S4 — Осень «Переход в наш мир».** (кульминация)
Листва желтеет, падают листья (частицы orange/brown). 3 осенних фото плавно перетекают
(cross-fade по скроллу) в свои АНИМЕ-версии — мир из пиксельной реальности превращается
в сказочный слой. Краски насыщаются, лёгкое свечение. Метафора «вот как я тебя вижу».

**S5 — Зима «Тишина и тепло».**
Снег, дерево в инее, тёплые окошки домика вдалеке, дым из трубы. 1 зимнее фото.
Текст-послание проявляется построчно по скроллу (GSAP SplitText). Тихо, интимно.

**S6 — День рождения «Снова весна».** (финал)
Круг замыкается: дерево взрывается цветением и светом, пиксельный фейерверк/сердечки в небе,
большое «С Днём Рождения, [имя]». Под деревом две фигурки + торт со свечками.
- если есть новое видео → кнопка «Открыть подарок» разворачивает его;
- **пиксельный сундук «Капсула воспоминаний»**: по клику открывается, из него
  «выпадают» карточки-ссылки на прошлые сайты:
    - [ссылка] 8 марта
    - [ссылка] 14 февраля (День святого Валентина)
    - [ссылка] Год отношений
    - [ссылка] Презентация на Canva (прошлый год)
  Карточки в пиксельных рамках, при наведении подпрыгивают.

## 5. Поведение скролла и анимации

- Lenis инициализировать и связать с GSAP ScrollTrigger (`lenis.on('scroll', ScrollTrigger.update)`,
  тикер GSAP крутит `lenis.raf`).
- Смена сезонов: один master ScrollTrigger со `scrub: true`, интерполирующий по прогрессу:
  цвет неба, цвет листвы, тип/цвет частиц, интенсивность света.
- Секцию с деревом пинить (`pin: true`) на время прохождения глав, чтобы дерево стояло, а мир менялся.
  Либо дерево фиксированным слоем поверх фоновых слоёв — выбрать что стабильнее на мобилке.
- Появление фото/текста — отдельные ScrollTrigger'ы с `toggleActions` / `scrub`.
- Параллакс-слои: разная скорость через `scrub` и разные `y`-сдвиги.
- Учитывать `prefers-reduced-motion`: при включённом — отключать тяжёлые частицы и автоплей,
  оставлять простые fade.
- На мобилке: уменьшить число частиц, отключить пиннинг если ломается, проверить тач-скролл с Lenis.

## 6. Проверка через Playwright

Установить `@playwright/test`. Написать тесты, которые гоняются в CI и локально:

1. **Загрузка**: страница открывается, нет ошибок в консоли, основной заголовок виден.
2. **Скролл-прогресс**: проскроллить по шагам (0%, 25%, 50%, 75%, 100%), на каждом шаге
   сделать скриншот — визуально проверить смену сезонов (скриншоты в `/tests/screenshots`).
3. **Секции**: каждая из 6 секций появляется при доскролле (проверка видимости/opacity).
4. **Видео**: элементы `<video>` присутствуют, постеры заданы, не автоплеят со звуком.
5. **Сундук/ссылки**: клик по сундуку раскрывает карточки, все ссылки имеют корректные href.
6. **Адаптив**: прогнать на viewport мобилки (390×844) и десктопа (1440×900),
   убедиться что нет горизонтального скролла и контент не наезжает.
7. **reduced-motion**: эмулировать `prefers-reduced-motion: reduce`, проверить что autoplay/частицы выключены.

Запуск: `npx playwright test`. Делать скриншоты артефактами, чтобы я мог глазами проверить сезоны.

## 7. Публикация на GitHub

- `vite.config.js`: `base: './'` (или `/<repo-name>/` если project pages) — иначе ассеты не найдутся на Pages.
- Сборка: `vite build` → `/dist`.
- Деплой: GitHub Actions workflow (`.github/workflows/deploy.yml`), который на push в `main`
  собирает и публикует `/dist` на GitHub Pages. Использовать `actions/deploy-pages`.
- `.gitignore`: `node_modules`, `dist` (если деплоит экшен), временные файлы.
- Большие видео: если суммарно тяжёлые — сжать (ffmpeg, H.264, ~720p, разумный битрейт),
  держать под лимитами репозитория; при необходимости вынести в Git LFS.
- README с инструкцией: как заменить фото/видео/подписи, как запустить локально (`npm i && npm run dev`).

## 8. Порядок работы (для Claude Code)

1. Инициализировать Vite-проект + установить зависимости (gsap, lenis, опц. howler, sharp для фото).
2. Сделать `ASSETS.md` и скачать/сгенерировать ассеты (раздел 3), записать лицензии.
3. Собрать каркас секций и слои фона/дерева, проверить пиннинг.
4. Реализовать master-таймлайн смены сезонов (scrub) + систему частиц.
5. Наполнить секции контентом с ПЛЕЙСХОЛДЕРАМИ под фото/видео/подписи/ссылки
   (чтобы пользователь потом заменил), пометить все плейсхолдеры как `TODO:`.
6. Финальная секция: сундук со ссылками (8 марта / 14 февраля / год отношений / Canva).
7. Написать Playwright-тесты (раздел 6), прогнать, приложить скриншоты сезонов.
8. Настроить Vite base + GitHub Actions деплой, написать README.
9. Прогнать сборку, убедиться что `/dist` открывается без ошибок.
